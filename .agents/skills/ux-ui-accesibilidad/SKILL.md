# Skill — UX/UI, diseño visual y accesibilidad

Evalúa o diseña interfaces con base en:

- claridad;
- jerarquía;
- navegación;
- responsive;
- accesibilidad;
- confianza;
- conversión;
- coherencia visual;
- identidad confirmada.

No uses criterios como “bonito” o “feo”.

Entrega:

1. Diagnóstico UX/UI.
2. Hallazgos.
3. Recomendaciones por sección.
4. Checklist responsive.
5. Checklist accesibilidad.
6. Próximos cambios.
