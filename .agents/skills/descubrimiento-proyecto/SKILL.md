# Skill — Descubrimiento de proyecto

Usa esta skill cuando el usuario pida iniciar, revisar, migrar, reconstruir o mejorar un proyecto.

Debes identificar:

- cliente o proyecto;
- problema;
- objetivo comercial;
- usuarios;
- acción esperada;
- alcance;
- restricciones;
- stack actual;
- entregables;
- fecha o urgencia;
- información pendiente.

Entrega:

| Área | Información confirmada | Pendiente | Riesgo |
| ---- | ---------------------- | --------- | ------ |

No propongas solución técnica antes de entender el problema real.
