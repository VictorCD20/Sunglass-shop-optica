# Skill — Arquitectura y generación de código

Antes de programar:

- inspecciona estructura;
- identifica framework;
- revisa rutas;
- revisa componentes;
- revisa servicios;
- revisa modelos;
- revisa estilos;
- identifica dependencias.

Al programar:

- cambios mínimos;
- reutilización;
- separación de responsabilidades;
- validación;
- manejo de errores;
- seguridad;
- pruebas.

No hagas refactor global si la tarea no lo requiere.
