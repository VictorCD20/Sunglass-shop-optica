# Skill — Seguridad defensiva web

Aplica esta skill en formularios, APIs, autenticación, bases de datos, despliegues, paneles admin, integraciones y sitios públicos.

- SQL injection;
- XSS;
- CSRF;
- CORS;
- rate limiting;
- spam;
- scraping;
- exposición de tokens;
- permisos;
- subida de archivos;
- errores internos;
- logs sensibles;
- variables de entorno;
- cabeceras de seguridad;
- cookies;
- privacidad.
